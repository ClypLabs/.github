## The play already happened. That's the point.

Every clip worth keeping is one you didn't see coming — so by the time you'd have hit
record, it's over. **ClypDat** keeps the last few minutes of your screen in memory at all
times. Press the hotkey *afterwards* and the moment is already saved, sitting in your
library, ready to trim.

No account. No subscription. No watermark, no upload queue, and nothing phoning home.
It's a GPL-licensed app that records to your disk and stays there.

|  |  |
| --- | --- |
| **Costs nothing to run idle** | Capture rides on your GPU's own encoder — NVENC, AMF or Quick Sync — so the buffer sits there without eating your frames |
| **Every source on its own track** | Game, chat and mic stay separate all the way into the editor, each with its own volume, instead of being mixed down and lost |
| **Trim without re-encoding the world** | An FFmpeg-backed editor with real waveforms, so cuts land where you actually hear them |
| **Updates you can verify** | Releases are signed with an offline key. An update that isn't signed by it doesn't install |

Bug reports and feature ideas are welcome in [the issue tracker](https://github.com/ClypLabs/ClypDat/issues) —

Security issues go through [the security policy](https://github.com/ClypLabs/ClypDat/security/policy)
